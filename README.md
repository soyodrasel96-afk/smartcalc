# 🧮 SmartCalc BD

একটি সহজ ও ব্যবহারকারী-বান্ধব স্মার্ট ক্যালকুলেটর অ্যাপ, বাংলা ইন্টারফেসসহ।

🔗 **লাইভ ডেমো:** https://soyodrasel96-afk.github.io/smartcalc/

## ✨ ফিচার

- 🔢 সায়েন্টিফিক ক্যালকুলেটর (sin, cos, tan, log, ln, √, x!, π, e, Ans, DEG/RAD)
- 🕘 হিস্ট্রি ও 🎤 ভয়েস ইনপুট
- 💰 EMI ক্যালকুলেটর
- 📐 ইউনিট কনভার্টার
- % শতকরা হিসাব
- 🎂 বয়স ক্যালকুলেটর
- 📅 তারিখ ক্যালকুলেটর (দুই তারিখের ব্যবধান)
- 🌙 ডার্ক থিম, মোবাইল-ফ্রেন্ডলি ডিজাইন
